# Security policy

## Supported versions

Only the latest release receives security fixes. Update with the installer
(see [Updating and uninstalling](README.md#updating-and-uninstalling)) before
reporting, and check that the issue still happens.

| Version | Supported |
|---|---|
| Latest release | Yes |
| Older releases | No |

## Report a vulnerability

Do not open a public issue, discussion or pull request for a vulnerability.

Report it privately through GitHub:
[Report a vulnerability](https://github.com/lesquel/termino/security/advisories/new)
(Security tab, then "Report a vulnerability").

Include:

- The output of `termino version`, your OS and architecture.
- The affected component (CLI, TUI, MCP server, widget, agent connector,
  board sharing, installer).
- Steps to reproduce, or a proof of concept.
- The impact you expect (for example data exposure, file overwrite, code
  execution).

## What to expect

termino is maintained on a best-effort basis. The maintainer aims to
acknowledge a report within 7 days, agree on a fix and disclosure date with
you, and credit you in the advisory unless you prefer otherwise.
