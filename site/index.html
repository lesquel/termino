Local-first · MIT · Go

Your Kanban board, right in the terminal.

termino keeps projects, boards and tasks in a single SQLite file on your machine, and gives you three ways in: a TUI, a CLI, and an MCP server your AI agents can use.

No accounts. No network. Opens no ports.

$ 
curl -fsSL https://raw.githubusercontent.com/lesquel/termino/main/install.sh | sh

Live demo

A real board, not a to-do list

The board above, the commands below and your shell prompt all read the same SQLite file. Change it from anywhere; everything else catches up.

Live refresh

The TUI polls SQLite PRAGMA data_version, so changes made by the CLI, a teammate's pull or an agent appear without a restart.

Cards you can read without color

Cards show as KEY-N with the theme's priority symbol: ▲ high, !!! critical, ▼ low; medium has none. The selected card is marked with >.

A small celebration

Moving a card into Done plays a short celebration, unless motion is off or NO_COLOR is set.

Features

One board. Three ways in.

Pick the interface that fits the moment. They all share one local database.

01

TUI

A Kanban board with live refresh: vim keys, filters, WIP limits, dialogs over the board and a Done celebration.

termino

02

CLI

Script everything: tasks, columns, members and sprints. Tasks are referenced as KEY-N.

termino add Fix login redirect
termino ls
termino task move WEB-4 Done

03

MCP

An MCP server on stdio with 13 tools, so agents such as Kiro read and update the same board you are looking at.

termino mcp

Also included

  • Setup wizard

    Eight steps: name, project, key, methodology, directory, a theme with a live board preview, and the shell widget.

  • Shell prompt widget

    A short summary when bash or zsh starts. Read-only, and it gives up silently after 100 ms.

    termino widget install

  • Markdown import

    Pull in checkbox tasks from Kiro tasks.md or any - [ ] list; --watch keeps syncing.

    termino import tasks.md --watch

  • Private by design

    One SQLite file under XDG paths. The binary opens no ports and makes no outbound connections.

AI agents

Your agent works the same board you do

Connect Kiro with one command. It talks to termino mcp over stdio, on your machine.

$ 
termino connect kiro

Adds a termino entry to ~/.kiro/settings/mcp.json and writes .kiro/steering/termino.md in the current directory. termino disconnect kiro removes only what connect added. termino mcp --read-only exposes only the read tools; --actor <name> sets the agent identity.

Teams

Share a board through the repo you already use

Plain-text files under .termino/ stay in sync with the board, and git carries them between people.

  1. 1

    Open your repository

    cd my-repo
  2. 2

    Write the board to .termino/

    termino share init
  3. 3

    Commit it like any other file

    git add .termino && git commit -m "chore: share the termino board" && git push

  • No server, no account

    git is the transport. Comments and activity history stay local.

  • One TOML file per task

    Edits to different tasks never conflict. A conflicted file is skipped and the status line warns ⚠ 1 shared file skipped — termino share status.

  • You stay in charge of git

    termino never commits, pushes or pulls. termino share off stops syncing.

Themes

Nine built-in themes. Or bring your own.

Pick one in the setup wizard, in settings (s) with a live preview, or from the CLI. Custom themes are a TOML file in ~/.config/termino/themes/.

Install

Install in one line

Linux, macOS and Windows on amd64 and arm64. MIT licensed.

Install script (Linux, macOS)

$ 
curl -fsSL https://raw.githubusercontent.com/lesquel/termino/main/install.sh | sh

Detects linux/darwin and amd64/arm64, verifies the SHA-256 against checksums.txt and refuses to install on a mismatch. The binary goes to $HOME/.local/bin.

Install script environment variables
VariableDefaultMeaning
TERMINO_VERSIONlatestRelease tag to install, e.g. v0.3.2
TERMINO_INSTALL_DIR$HOME/.local/binWhere the binary goes

Go

$ 
go install github.com/lesquel/termino/cmd/termino@latest

Requires Go 1.25+. No cgo is needed: the SQLite driver is pure Go.

Release archives

Every release publishes archives for linux, darwin and windows on amd64 and arm64, plus checksums.txt with SHA-256 sums. On Windows, download the .zip and put termino.exe on your PATH.

Browse releases on GitHub

First run

termino                # setup wizard, then the board
termino connect kiro   # register the MCP server so Kiro can use the board
termino doctor         # confirm the install, database and integrations are healthy
